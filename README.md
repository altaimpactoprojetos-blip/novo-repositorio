# Mulheres com Visão

Site institucional e painel administrativo do movimento **Mulheres com Visão**, idealizado pela **Pastora Elaine Aguiar**.

- Site público: Início, Sobre nós, Eventos, Galeria, Mensagens e testemunhos, Contato
- Painel administrativo em `/admin` (eventos, galeria, conteúdo, testemunhos, equipe, contatos e usuários)
- Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · shadcn/ui · Framer Motion · Supabase

```bash
npm install
```

```bash
npm run dev
```

📖 Configuração, primeiro acesso e publicação: veja **[MANUAL.md](./MANUAL.md)**.
